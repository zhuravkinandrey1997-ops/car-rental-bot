Реализуй публичную ветку клиентского онлайн-бронирования для пользователей с сайта:

1. Разделение доступа в команде /start:
- Если telegram_id есть в листе «Менеджеры» -> открывать панель управления сотрудника.
- Если пользователя НЕТ в менеджерах -> запускать клиентский сценарий FSM: ClientBookingState.

2. Сценарий клиента:
Шаг 1: Выбор автомобиля (кнопки активных авто из листа «Автомобили») + даты аренды (инлайн-календарь).
- Проверка доступности дат. Если занято — предложить другие даты или другие авто.
- Расчет стоимости: (кол-во суток * суточный тариф авто).

Шаг 2: Доставка:
- Вопрос: "Нужна ли подача/доставка автомобиля?"
- Кнопки:
  [ 🏢 Заберу в офисе (Бесплатно) ]
  [ ✈️ Аэропорт (+ 3 000 RUB) ]
  [ 📍 Доставка по адресу (+ 3 000 RUB) ]
- При выборе доставки запросить адрес и прибавить стоимость доставки к расчету.

Шаг 3: Контакты клиента:
- Запросить ФИО и номер телефона (через кнопку [ 📱 Поделиться контактом ] или текстом).

Шаг 4: Предоплата и реквизиты:
- Показать расчет:
  "Авто: {авто} ({даты})
   Аренда: {сумма_аренды} RUB
   Доставка: {доставка} RUB
   ИТОГО к оплате: {общая_сумма} RUB
   Предоплата для фиксации брони: {предоплата} RUB"
- Отправить реквизиты/инструкцию по оплате и сообщение:
  "Для подтверждения бронирования, пожалуйста, отправьте фото или PDF чека об оплате предоплаты."

Шаг 5: Обработка чека:
- Клиент загружает фото/документ чека.
- Бот записывает бронь в лист «Бронирования»:
  * ID Авто, Марка, Даты, ФИО, Телефон.
  * Сумма брони, Задаток/Предоплата = внесенная сумма.
  * Источник (столбец BR) = "Сайт".
  * Статус = "Ожидает подтверждения".
- Переслать чек и карточку заявки в чат администраторов/менеджеров:
  "🔔 Новая бронь с сайта!
   Авто: {авто} | Клиент: {ФИО} ({телефон})
   Даты: {даты} | Доставка: {доставка_адрес}
   Предоплата: {предоплата} RUB"
   Кнопки для админа: [ ✅ Подтвердить бронь ] [ ❌ Отклонить ]
- При нажатии [ ✅ Подтвердить бронь ] админом:
  * Статус в таблице меняется на "Подтверждена".
  * Клиенту бот отправляет радостное уведомление: "🎉 Ваша бронь успешно подтверждена! Ждём вас."

Внедри клиентский FSM, проверку прав и уведомления админов. Перезапусти бота.
