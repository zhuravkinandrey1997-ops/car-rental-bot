Реализуй сценарий FSM при нажатии кнопки «👤 Связь с менеджером» в клиентском боте:

1. Хэндлер нажатия кнопки «👤 Связь с менеджером»:
Сделай фильтр по тексту (F.text.contains("Связь с менеджером") | F.text == "👤 Связь с менеджером").
При нажатии:
- Установить FSM-состояние: ManagerContactState.waiting_for_contact
- Отправить клиенту сообщение:
  "📞 <b>Связь с менеджером Leon Rental</b>

  Пожалуйста, введите ваш <b>номер телефона</b> или <b>Telegram-username</b> (например, @username), чтобы менеджер мог с вами связаться:

  <i>Вы также можете отправить номер одной кнопкой ниже:</i>"
- Клавиатура:
  [ 📱 Отправить мой номер телефона (request_contact=True) ]
  [ ❌ Отмена ]

2. Обработка ввода контакта (состояние waiting_for_contact):
При получении контакта (F.contact | F.text):
- Если нажата «❌ Отмена»: сбросить состояние (state.clear()) и вернуть главное меню.
- Если отправлен контакт или текст:
  contact_data = message.contact.phone_number if message.contact else message.text.strip()
  client_name = message.from_user.full_name
  client_username = f"@{message.from_user.username}" if message.from_user.username else "не указан"
  client_id = message.from_user.id

  1) Клиенту отправить сообщение и вернуть главное меню:
  "✅ <b>Запрос отправлен!</b>
  Дежурный менеджер Leon Rental уже получил ваши контакты и свяжется с вами в течение 10-15 минут."

  2) Сформировать уведомление для менеджеров:
  "🔔 <b>ЗАПРОС СВЯЗИ С МЕНЕДЖЕРОМ!</b>

  Клиент ждёт консультации:
  • <b>Имя:</b> {client_name}
  • <b>Контакт:</b> <code>{contact_data}</code>
  • <b>Telegram:</b> {client_username} (ID: <code>{client_id}</code>)
  • <b>Время:</b> {текущее время МСК}"

  3) Отправить уведомление во флот-бот (@Leon_Rental_Fleet_bot):
  Разослать это сообщение менеджерам/админам из листа «Менеджеры» (или в рабочий чат автопарка FLEET_CHAT_ID) через инстанс fleet_bot.

  4) Очистить FSM-состояние (await state.clear()).

Внедри этот FSM-диалог для связи с менеджером и перезапусти бота.
